# 🌐 Developer Portfolio

*A personal portfolio showcasing my projects, technical skills, certifications, and software development journey.*

---

## 📖 Overview

This repository contains the source code for my personal developer portfolio website. It serves as a central hub for showcasing the projects I've built, the technologies I work with, and the skills I've developed throughout my software engineering journey.

The website is built using the **Massively** HTML5 UP template and has been customized to reflect my personal branding and portfolio.

---

## ✨ Features

* 👨‍💻 About Me section
* 📂 Project showcase
* 💼 Technical skills
* 📜 Certifications
* 📄 Downloadable résumé
* 📱 Responsive design
* 🌐 Social media links
* ⚡ Fast and lightweight

---

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/portfolio.git
```

---

### 2️⃣ Open the Project

Open the project folder in **Visual Studio Code**.

---

### 3️⃣ Launch the Website

Open **index.html** directly in your browser, or use the **Live Server** extension in Visual Studio Code for a better development experience.
